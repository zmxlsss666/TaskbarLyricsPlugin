# TaskbarLyricsPlugin
一个适用于 Salt Player For Windows 的任务栏歌词插件
## 安装方法
1. 从 [Release页面](https://github.com/zmxlsss666/TaskbarLyricsPlugin/releases) 下载最新版本
2. 解压TaskbarLyricsPlugin.zip
3. 运行TaskbarLyrics_Setup.exe（由7zip SFX生成，如有安全方面的疑虑可[自行编译](https://github.com/zmxlsss666/TaskbarLyricsPlugin-resources)）
5. 进入SPW→设置→创意工坊→模组管理→导入→plugin-TaskbarLyricsPlugin-2.0.0.zip→启用并重启

## 注意事项
仅适配原版任务栏
